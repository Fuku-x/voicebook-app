# VoicebookLM

## 概要
VoicebookLMは、音声録音と文字起こし機能を備えたメモアプリケーションです。ユーザーは音声を録音し、その内容を管理・編集することができます。

## 機能一覧
このアプリケーションには以下の主要な機能が含まれています。

* **ホーム画面**: メモの一覧表示と管理を行います。
* **検索機能**: 保存されたメモや文字起こし内容を検索します。
* **録音機能**: 音声の新規録音を行います。
* **メモ詳細**: メモの詳細情報の閲覧および編集が可能です。
* **文字起こし編集**: 自動生成された文字起こしテキストを修正・編集できます。
* **アカウント管理**: ユーザー情報の確認と設定を行います。
* **認証**: ログイン画面によるユーザー認証機能を提供します。

## 技術スタック
* TypeScript
* React
* Tailwind CSS (推定)
* Lucide React (アイコン)

## ディレクトリ構造
* `components/`: アプリケーションの各画面およびUIコンポーネント
* `components/ui/`: 再利用可能な基本UIコンポーネント群
* `styles/`: スタイルシート
* `guidelines/`: プロジェクトガイドライン
* `App.tsx`: メインアプリケーションコンポーネントとルーティング定義
